The app, screen by screen.

These are static renders of the real GalliRent screens — same layout, typography, colours and copy as the Expo Router/React Native code in this repo, scaled to a 393×852 phone. Photos are sample Bengaluru properties and all figures are demo data. This is not a web build: the shipping product is an Android .aab, so Ads, the SSV unlock, Play Billing and Maps only run on a device.

Tip: every phone frame scrolls independently — hover a frame and scroll to see the full screen.

What this preview is

A static HTML mirror of the React Native screens for design review. It is documentation only — it is excluded from the Android bundle and is not a web/PWA target.

What needs a real device

AdMob fill and the rewarded-ad lock, Google's signed admob-ssv callback, Google Play Billing sheet, Maps key, camera/GPS permissions and push of the actual .aab.

Where the truth lives

UI: app/, components/, lib/theme.ts. Economics and unlocking: supabase/schema.sql. Release steps: README.md.
